# Todo App

A simple command-line Todo application built with Python.


## Features

- Add tasks
- View tasks
- Delete tasks
- Mark tasks as completed
- JSON-based task storage
- Automatic saving
- Input validation

## How to Run

1. Clone the repository.
2. Navigate into the project directory.
3. Run the program:

```bash
python3 main.py
